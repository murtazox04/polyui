A dashboard from a live run

A model was asked "How is the store doing this year? Build me a dashboard." against the shop demo. It wrote the SQL and the layout; the numbers came from the queries. This is the ui.open the server sent, drawn here by the wasm core and the web renderer in your browser.

What the model saw instead of the numbers

The model's copy of this surface keeps {"$ref": "query:q1"} and {"$ref": "stat:q2"} where the rows and values are. Its tool result shows them as [ref]. Only the client copy, this message, carries the data.

Source: shop_dashboard_open.json. Guide: Dashboards from your own data.
